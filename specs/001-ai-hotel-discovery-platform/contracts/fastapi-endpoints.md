# FastAPI Endpoint Contracts

**Layer**: AI Service (FastAPI)
**Date**: 2026-05-23
**Note**: These are the contracts the FastAPI AI service exposes to the Nuxt 3 frontend.
They are NOT the Spring Boot wrapper APIs — those are documented in `api/Hotel-Search-doc.md`.

---

## Base URL (local dev)

```
http://localhost:8000
```

Nuxt 3 proxies `/api/*` → `http://localhost:8000/*` via `nuxt.config.ts` `nitro.devProxy`.

## Endpoints

### `GET /chat/search` — Conversational Hotel Search (SSE)

Accepts a natural-language hotel search query and streams results as Server-Sent Events.

**Query Parameters**:

| Parameter | Type | Required | Description |
|---|---|---|---|
| `sessionId` | string (UUID) | Yes | Client session identifier |
| `query` | string (URL-encoded) | Yes | Natural-language search query |

**Response**: `text/event-stream`

**SSE Event Types**:

| Event | Data Schema | When Emitted |
|---|---|---|
| `thinking` | `{ "message": string }` | AI is extracting intent or calling AutoSuggest |
| `hotels_batch` | `{ "hotels": HotelCard[], "batchIndex": number }` | Each Search By Poll response with hotel results |
| `search_complete` | `{ "totalHotels": number, "searchKey": string, "autoSuggestId": string }` | Poll loop completed successfully |
| `error` | `{ "code": ErrorCode, "message": string, "recoverable": boolean }` | Any unrecoverable failure during the search flow |

**Error codes**:

| Code | Meaning | Recoverable |
|---|---|---|
| `NO_AUTOSUGGEST_RESULT` | Destination not found | true — user can rephrase |
| `VALIDATION_ERROR` | Invalid search parameters extracted | true |
| `NO_RESULT` | No hotels matched search criteria | true |
| `DOWNSTREAM_NULL` | Spring Boot vendor returned null | true — user can retry |
| `DOWNSTREAM_TIMEOUT` | Spring Boot timed out | true |
| `POLL_TIMEOUT` | 60 s poll timeout reached | true — partial results may exist |
| `TOKEN_REFRESH_FAILED` | Token API unreachable | false |
| `INTERNAL_ERROR` | Unexpected AI service error | false |

**Example flow**:
```
event: thinking
data: {"message": "Finding hotels in Mumbai..."}

event: hotels_batch
data: {"hotels": [{"hotelId": "H1001", "hotelName": "...", ...}], "batchIndex": 0}

event: hotels_batch
data: {"hotels": [{"hotelId": "H1002", ...}], "batchIndex": 1}

event: search_complete
data: {"totalHotels": 12, "searchKey": "abc-123", "autoSuggestId": "AS456"}
```

### `GET /hotels/{hotelId}` — Hotel Details

Fetches full hotel profile for the given hotel ID.

**Path Parameters**:

| Parameter | Type | Required | Description |
|---|---|---|---|
| `hotelId` | string | Yes | Hotel ID from search results |

**Query Parameters**:

| Parameter | Type | Required | Description |
|---|---|---|---|
| `sessionId` | string | Yes | Session ID (used to retrieve `searchKey` from Redis) |

**Response**: `application/json`

**Success (200)**:
```json
{
  "success": true,
  "capability": "HOTEL_DETAILS",
  "data": {
    "hotelData": { "...": "full hotel details from Spring Boot" },
    "searchKey": "ec1d0777-..."
  }
}
```

**Error (404 — No Result)**:
```json
{
  "success": false,
  "code": "NO_RESULT",
  "message": "Hotel details are not available for this hotel.",
  "recoverable": true
}
```

**Error (502 — Downstream Null)**:
```json
{
  "success": false,
  "code": "DOWNSTREAM_NULL",
  "message": "Unable to retrieve hotel details. Please try again.",
  "recoverable": true
}
```

**Error (504 — Downstream Timeout)**:
```json
{
  "success": false,
  "code": "DOWNSTREAM_TIMEOUT",
  "message": "Hotel details request timed out. Please try again.",
  "recoverable": true
}
```

### `GET /hotels/{hotelId}/rooms` — Room Details

Fetches available room categories for the given hotel.

**Path Parameters**:

| Parameter | Type | Required | Description |
|---|---|---|---|
| `hotelId` | string | Yes | Hotel ID from search results |

**Query Parameters**:

| Parameter | Type | Required | Description |
|---|---|---|---|
| `sessionId` | string | Yes | Session ID (used to retrieve `searchKey` + `autoSuggestId` from Redis) |

**Response**: `application/json`

**Success (200)**:
```json
{
  "success": true,
  "capability": "ROOM_DETAILS",
  "data": {
    "roomData": {
      "hotelId": "39679265",
      "standardRooms": ["..."]
    },
    "pgRedirectUrl": "https://payment-gateway.example.com/redirect?token=..."
  }
}
```

**Note**: `pgRedirectUrl` is generated by the AI service from session context and returned alongside room data so the frontend can open it in a new tab on room selection.

**Error responses**: Same error code patterns as Hotel Details above, plus:

| Code | HTTP | Meaning |
|---|---|---|
| `VALIDATION_ERROR` | 400 | Missing hotelId or other required field |
| `NO_RESULT` | 404 | No rooms available for this hotel |
| `DOWNSTREAM_NULL` | 502 | Downstream returned null |
| `INTERNAL_ERROR` | 500 | Unexpected error |

## CORS Configuration

For local development, FastAPI allows requests from `http://localhost:3000` (Nuxt 3 dev server).

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:3000"],
    allow_methods=["GET", "POST"],
    allow_headers=["*"],
)
```

---

## Authentication

No authentication between frontend and FastAPI for MVP. Session ID passed as query parameter is sufficient for single-user local development. Future: add session token validation via middleware.
